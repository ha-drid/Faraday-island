# Остров Фарадея

## Запуск на Windows

1. Распакуй архив целиком в одну папку. Для запуска нужен Python 3.
2. Дважды щёлкни по `start-windows.bat`. Игра откроется в браузере. Если вкладка не открылась автоматически, введи в адресную строку `http://127.0.0.1:8000/`.
3. Пока играешь, держи окно запуска открытым. Чтобы остановить сервер, нажми **Ctrl+C** в этом окне.

Также можно открыть терминал в распакованной папке и выполнить `py -3 start-local.py` (Windows) или `python3 start-local.py` (macOS и Linux).

Игра обращается к Three.js на `cdn.jsdelivr.net`. Для первой загрузки нужна доступная сеть.

## Почему двойной щелчок по index.html не запускает сцену

Так браузер открывает страницу по адресу `file://` и может блокировать загрузку соседних JavaScript-модулей. Открывай игру по адресу локального сервера. В HTML путь к сцене должен быть `import('./scene.mjs')`. Префикс `./` означает «из текущей папки».

Для публикации на GitHub Pages загрузи файлы игры с сохранением структуры папки, включая `.nojekyll`. Файлы `start-local.py` и `start-windows.bat` нужны только для запуска на своём компьютере.
